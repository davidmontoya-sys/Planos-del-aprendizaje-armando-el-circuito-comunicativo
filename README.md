## 🔌 3. Componentes del Circuito Comunicativo Virtual

Para entender cómo viaja el conocimiento en nuestra aula virtual, hemos diseñado el circuito bajo los siguientes componentes esenciales:

### 👤 A. Los Nodos (Roles)
*   **Emisor (Docente / Facilitador):** Es quien codifica los objetivos de aprendizaje, diseña las guías de actividades y plantea los retos en Moodle.
*   **Receptor (Estudiantes / Nosotros):** Recibimos, decodificamos e interpretamos las instrucciones para transformarlas en conocimiento práctico a través de herramientas como GitHub.

### 🛣️ B. Las Rutas de Flujo (Canales y Plataformas)
El mensaje pedagógico no viaja por un solo cable; utiliza una red interconectada:
1.  **Moodle (Canal Formal/Asincrónico):** Donde se aloja la estructura del curso, las rúbricas y el espacio de entrega de tareas.
2.  **GitHub (Canal Práctico/Colaborativo):** El entorno donde el equipo co-crea, edita el código y visualiza el proyecto final de forma transparente.
3.  **WhatsApp / Teams (Canal Inmediato/Sincrónico):** La vía rápida para coordinar la división de tareas y resolver dudas instantáneas entre los integrantes.

### 💥 C. Las Interferencias (Ruido en el Circuito)
En un entorno virtual, el flujo de aprendizaje puede sufrir interrupciones o "caídas de tensión". Hemos detectado las siguientes:
*   **Ruido Técnico:** Conexiones a internet inestables que impiden cargar la plataforma o fallos temporales en los servidores de GitHub/Moodle.
*   **Ruido Cognitivo:** Instrucciones ambiguas o mala interpretación de los criterios de evaluación por parte del equipo receptor.
*   **Ruido de Coordinación:** Desfases de tiempo en la comunicación asincrónica entre los miembros del grupo (falta de respuestas oportunas).

### 🔄 D. La Retroalimentación (Feedback o Cierre del Circuito)
El circuito se completa y se vuelve bidireccional cuando:
*   El docente revisa el repositorio de GitHub y califica en Moodle, enviando comentarios de mejora.
*   El equipo analiza los comentarios, corrige los errores y consolida el aprendizaje, asegurando que el conocimiento fluya de manera cíclica.
